# CTR Brașov Cloudflare Workers

Codul Worker-elor Cloudflare folosite de aplicația CTR Brașov.

## Structură

- `ctr-brasov-weather/` — ANM + istoric meteo D1
- `ctr-brasov-pg-weather/` — Paragliding România + istoric PG D1
- `ctr-brasov-notam/` — NOTAM / restricții ROMATSA

Worker-ele existente din Cloudflare rămân active. Migrarea în GitHub se face pe rând, fără întreruperea serviciilor.
